# Source Connector Inventory

Start here. A GTM Brain without connected sources becomes a polished opinion doc.

## Workflow

1. List available connectors, local files, reports, docs, exports, and credentials without exposing secrets.
2. Create or update `systems/tools.md` with each source's status, use cases, and limits.
3. Create or update `systems/sources.md` with source priority and section routing.
4. Create or update `systems/source-coverage.md` or a coverage section showing connected, partial, blocked, and missing sources.
5. Recommend the first evidence bundle for each canonical section.

## Use The Reference

Read `../../references/tool-connection-map.md` before drafting the tool map.

## Key Rule

For every source, write both:

- `Use for`
- `Do not use for`

This prevents CRM, campaign tools, support conversations, and old notes from being overtrusted.
